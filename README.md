# 🤖 AI Website Reverse Engineer

An AI-powered tool that analyzes any website from its URL and rebuilds its design and components using code.

## 💡 Concept

Enter a website URL, and the AI analyzes its design, sections, and components, then generates a new version using code with a live preview.

**URL → AI Analysis → Code Generation → Live Preview**

## ✨ Features

* AI-powered website analysis
* Automatic component and section detection
* AI-generated code
* Live website preview
